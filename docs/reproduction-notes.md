# 资料完善清单

[返回项目首页](../README.md)

已提供：硬件 `.epro`、BOM v0.96、六盘打印工程、rc.7 源码与刷写包、从作者视频整理的图文教程。下面列出复刻时仍需要补齐或确认的具体信息，避免把未知细节写成已验证参数。

| 项目 | 已知内容 | 仍需补充 |
| --- | --- | --- |
| PCB 制造参数 | 主控板两层、厚约 1.6 mm；灯板四层、1.6 mm | 主控板厚度需核对订单，补表面处理与最终生产版本 |
| 麦克风模块 | INMP441 与 GPIO12/13/14、左声道 | 清晰的模块端/PCB 端线序照片、供电连接与固定位置 |
| 电池 | 单节 3.7 V、850 mAh、选项 603443 | 保护规格、插头线序和确认过的安装余量 |
| 装配小辅料 | 视频有电池固定双面胶 | 实际耗材用量，是否还有脚垫等未列附件 |
| 使用兼容性 | 视频展示和 rc.7 历史测试摘要 | 具体系统/桌面版本与 BLE 重连、冷启动等测试结果 |
| 使用许可 | 文件已公开分享 | 作者确定硬件、结构与软件分别使用的许可证 |

五个不同名称的六盘总工程已核对为同一内容，统一入口见[打印说明](printing.md)。这是文件一致性核对，不等于确认每个零件都已在所有打印机上完成实打。

已确认的补充：黑色键帽 ¥0.60 为整套价格，BOM 数量 1 按一套理解；作者的[完整 B 站视频](https://b23.tv/TivtklJ)已加入首页与视频导览。

这份清单不要求重新拍摄整个装配过程。后续若补图，最有价值的是麦克风接线、电池连接器极性、两板排线触点方向与 PCB 下单参数截图。
